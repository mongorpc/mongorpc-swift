# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-01-05

### Added
- **Admin SDK**: Added `AdminClient` struct for privileged operations.
- **Async/Await**: Full Swift 5.5 concurrency support.
- **Combine**: Publishers for `watch` and snapshot operations.

### Changed
- **Dependencies**: Updated `grpc-swift` and `protobuf` dependencies.
- **API**: Standardized `MongoRPC` client initialization.

### Fixed
- **Real-time Sync**: Resolved issues with stream connectivity and decoding.
